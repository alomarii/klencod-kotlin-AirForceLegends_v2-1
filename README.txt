Air Force Legends — Android Studio project
Developed & programmed by: Mohammed Al-Omari (محمد العمري) — 730215825

Build APK:
1) Open this folder in Android Studio (Hedgehog or newer, JDK 17). Let Gradle sync.
2) Build > Build APK(s)  (or Build > Generate Signed Bundle/APK for Play Store).
The game itself is in app/src/main/assets/www/index.html (also playable in any browser).
